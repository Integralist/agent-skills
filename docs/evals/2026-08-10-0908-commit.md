## Suite defects

Carried from run 1 and still open, plus what run 2 added.

1. **Transcripts are not durable.** Executors finish and go idle without
   reporting. Run 2 instructed every agent that its final message must *be* the
   report; all five still went idle, two of them twice more after being chased.
   This is not fixable by prompting. The executor must write its transcript to a
   file inside the sandbox as it works, and the orchestrator must grade from
   that file — disk survives an idle agent, an unsent message does not.
1. **A same-day re-run overwrites its predecessor.** The skill's Report rule
   would have destroyed run 1's file, which is the better record. Results need a
   time component in the filename so runs accumulate.
1. **Two checks are unverifiable from disk by construction.** "Stages by name"
   and "inspects before committing" leave no trace distinguishable from their
   negation. They are worth keeping, but only once transcripts are durable —
   until then they can only ever report `unverified`.
1. **Fixed since run 1:** the contradictory `single-file-fix` setup, and the
   vacuous unpushed check. Both confirmed working above.
