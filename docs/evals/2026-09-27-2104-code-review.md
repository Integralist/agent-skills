## Harness defects

These affect how this suite runs, not the skill's score:

- **Concurrent-subagent cap (20).** Eight executors fanning out 4–5 reviewers
  each exceeded it. `performance-n-plus-one` and most of
  `spec-conflict-completed-project` ran their dimensions inline. Run code-review
  cases in batches of about three.
- **Hand-backs routed to the orchestrator.** Nested reviewers and verifiers
  delivered their reports to the orchestrating thread, not to their executor,
  and most ended their first run without a hand-back. Executors recovered by
  messaging each subagent or reading results from
  `.evals-sandbox/<id>-results/<role>.json`. Have executors require the file
  route from the start.
- **Executor brief blocked a linked file.** The brief limited reads to the
  three skill files, so most executors never read
  `shared/SUBAGENT-STEERABILITY.md` and picked model tiers themselves. Allow
  files the skill links to.
- **No `max_turns` parameter.** The Agent tool cannot set the skill's turn
  limits; no subagent reported hitting one.
