# Organizational knowledge sources

When available, search team context beyond code and the web through these MCP
sources:

- **Confluence** (Atlassian MCP): pages, specs, design docs, and runbooks;
  read full documents.
- **Google Drive** (Google Drive / Workspace MCP): docs, sheets, and slides;
  search by topic keywords.
- **Slack** (Slack MCP): conversations, decisions, and tribal knowledge, not a
  document store. Search public channels and threads; cite useful messages
  with a permalink and quote the relevant snippet.

## When a source is unavailable

If an MCP server is unavailable, uninstalled, or misconfigured, tell the user
which source you couldn't reach, then continue with available sources. Don't
block on a missing integration.
