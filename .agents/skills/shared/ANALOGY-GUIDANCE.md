# Analogy Guidance

Use an analogy to give an abstract idea a familiar foothold. Prefer one the
learner has shown they know; don't guess their interests.

When using one:

1. Map the relevant parts.
2. Name where it stops matching.
3. Restate the precise concept.
4. Check understanding with a fresh example of the real concept, not only the
   analogy.

Skip analogies when a direct example or diagram is clearer, or when they blur a
technical constraint.
