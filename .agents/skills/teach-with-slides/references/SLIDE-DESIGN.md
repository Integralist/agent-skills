# Slide Design and Themes

Read this reference after confirming the topic, format, and theme, before
outlining or drafting slides.

## Slide structure

- Teach one idea per slide, using short phrases, sparse bullets, generous
  whitespace, and clear hierarchy.
- Use a warm, encouraging voice that invites rather than talks down.
- Define technical terms on first use and prefer concrete examples.
- Follow [ANALOGY-GUIDANCE.md](../../shared/ANALOGY-GUIDANCE.md) when using
  analogies.
- Add a small knowledge check when it reinforces learning; never let it
  replace or weaken the explanation.

## Diagrams

Use Mermaid when a flow, hierarchy, cycle, timeline, or relationship is easier
to understand visually. Choose the smallest diagram that works. Render it in
the deck's format. Keep standalone Mermaid source or images only if the user
asks or the deck needs them to be reproduced.

## Claude-inspired theme (default)

Use warm oranges, beiges, and browns with strong text contrast and restrained
accents. This is a design direction, not an official Anthropic palette; do
not imply endorsement or brand compliance.

## Fastly-inspired theme (informal)

Use for quick decks for Fastly colleagues, building from scratch unless the
user asks for an authorised template. This is a visual reference, not official
collateral. Legibility and teaching come before brand fidelity; never label
the deck approved. Use one theme per deck unless the user asks for a hybrid.

- **Colour:** Fastly Red `#FF282D` is for accents only, never large areas of
  body text. Use icon blue `#0073EB`, white, and black. Tints may distinguish
  chart elements; mention unusual colour choices in the delivery message.
- **Type and icons:** Inter Tight at normal weight. Use Google Material
  Symbols at weight 300, grade 200, optical size 48, rendered at 50, in blue,
  white, or black.
- **Layouts:** title, agenda, speaker intro, meet the team, numbered section
  break (`01`), content with or without subtitle, content with photo,
  full-width image or diagram, two- to four-panel, 4- or 6-tile, big stat,
  big statement, customer quote, case study, 4x4 or 5x5 table, Q1–Q4
  timeline, Q&A, and thank you. Adapt a layout when the topic needs it. Use
  no more than four bullets per slide.
- **Leave out:** copyright footer unless asked; if asked, use
  `©<current year> Fastly, Inc.` on every content slide. Do not use a logo
  the user has not supplied or confirmed as approved, invented customer
  names, retired Signal Sciences branding, gradients, drop shadows, or clip
  art.
