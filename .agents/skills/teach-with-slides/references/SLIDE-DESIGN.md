# Teaching with slides

Read after confirming the topic, format, and theme, before outlining slides.
Load [design](../../design/SKILL.md) first for theme and presentation rules.

- Use a warm, encouraging voice that invites rather than talks down.
- Define technical terms on first use and prefer concrete examples.
- Follow [ANALOGY-GUIDANCE.md](../../shared/ANALOGY-GUIDANCE.md) when using
  analogies.
- Add a small knowledge check when it reinforces learning; never let it
  replace or weaken the explanation.

Teaching content belongs here. Theme, layout, typography, and diagram
appearance belong to design's shared references, not a second local palette.
